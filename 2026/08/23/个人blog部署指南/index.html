个人blog部署指南

|浏览量:

  1. 安装 Node.js
  • 更新软件源列表
  • 安装 Node.js 和 npm
  • 安装验证
  1. 安装 Git
  • 安装 Git
  • 安装验证

二、安装 Hexo

  1. 安装 Hexo
  • 安装 Hexo
  • 安装验证

三、博客项目创建

  1. 创建博客项目, 并进入项目目录,这里以 blog 为例
  2. 初始化 Hexo 项目
  3. 项目验证
  4. 访问 http://localhost:4000 即可查看初步搭建好的博客

四、博客项目配置

  1. 进入配置文件
  2. 站点基本信息设置
  3. 主题设置, 这里以 Butterfly 为例
  • 安装 Butterfly 主题
  • 配置主题
  1. 关闭 _config.yml 文件, 并保存
  2. 建立独立主题配置文件, 之后可在 _config.butterfly.yml 中配置主题相关参数
  3. 本地预览 Butterfly 主题博客
  4. 访问 http://localhost:4000 即可查看 Butterfly 主题博客

五、博客部署到 GitHubPages

  1. 创建 GitHub 仓库
  • 登录 GitHub 并创建一个新的仓库, 仓库名称为 你的用户名.github.io
  • 仓库设置为公开
  1. 配置 _config.yml 文件, 此处路径为 blog/_config.yml
  • 设置网址
  • 部署设置
  1. 配置 SSH 密钥
  • 生成 SSH 密钥 后续直接回车即可
  • 查询并复制公钥
  • 登录 GitHub 并添加公钥到 SSH 密钥对
  • 点击设置 -> SSH 密钥对
  • 点击添加密钥对
  • 输入密钥对名称, 例如 blog
  • 粘贴公钥内容
  • 点击添加密钥对
  • 测试 SSH 连接 如果返回 “Hello, 你的用户名! You’ve successfully authenticated, but GitHub does not provide shell access.” 则表示配置成功
  1. 安装 Hexo 插件
  2. 部署博客 等待 5-10 分钟即可在 https://你的用户名.github.io/你的用户名.github.io 查看部署好的博客
