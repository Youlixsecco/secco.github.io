一、blog 图片上传成功，本地预览无问题，但是推送到服务器后图片却无法正常加载 检查图片路径是否正确，写入路径与真实路径有较大可能存在大小写差异 关闭 git 默认的忽略大小写功能1git config --global core.ignorecase false 检查配置是否生效1git config --global core.ignorecase 输出 false 表示配置生效 重新提交即可恢复正常加载 二、图片在本地设备可查看，但是本地预览无法正常加载 开发者上传图片前进行了旋转图片的操作，图片极有可能已经损坏 将图片回退到旋转前的状态，建议使用 https://utilitykit.tools/image-rotate-90-180 旋转图片并下载
